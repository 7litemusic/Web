# 7lite Music — Official Web & Digital Store

> **"Sonido que se siente"** — Fusión entre ingeniería en sistemas, precisión técnica (cero latencia) y arte callejero.

Sitio web oficial y plataforma digital para **7lite Music** (`7litemusic.com`). Construido con HTML5 semántico, Tailwind CSS y JavaScript moderno (ES6+).

---

## ⚡ Características Principales

- **Diseño Cyber-Mesh & Audio Engineering**: Estética minimalista, oscura y de alto contraste (Carbon Black `#171717`, acentos en `#4EFFAE`, `#00BFFF`, `#4E00FF`).
- **Navegación 100% VH**: Experiencia de pantalla completa con scroll snap optimizado.
- **Suite Interactiva "7lite Studio Lab"**:
  - **Mini-Consola de Stems (4-Track Mixer)**: Mezclador en tiempo real con Web Audio API (Drums, 808 Bass, Melodía, Vocal FX), faders táctiles, Solo, Mute y Vúmetros estéreo LED de 8 segmentos.
  - **MPC Tap Tempo BPM Finder**: Detección de tempo en vivo con pad táctil (ratón o barra espaciadora) y recomendación inteligente de canal sonoro.
  - **Cursor HUD Láser Cibernético**: Retícula técnica con inercia suave y ondas acústicas (*Sonic Ripples*).
  - **Micro-sonidos de UI Analógicos**: Clics mecánicos de estudio analógico sintetizados con Web Audio API y botón conmutable en Navbar.
- **Fondo Interactivo 2D**: Malla de ondas de audio reactivas al movimiento del cursor.
- **Efectos 3D Tilt & Mouse Spotlight**: Tarjetas de canales y licencias con iluminación volumétrica dinámica.
- **Terminal Text Scramble**: Efecto de desencriptación hacker/ingeniería en titulares.
- **Formulario de Contacto Funcional**: Conectado a Formspree con validación y envío AJAX asíncrono.
- **Canales Directos**: Integración con WhatsApp VIP, Correo Electrónico, Instagram y TikTok oficiales.
- **Integración BeatStars**: Catálogo oficial embebido para compra y descarga inmediata 24/7.
